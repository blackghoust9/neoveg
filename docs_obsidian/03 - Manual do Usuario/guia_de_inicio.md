# Guia de início

O Neoveg abre direto no espaço de trabalho com um projeto vazio (0 faixas, 0 mídias). A janela do dock está descrita em [[especificacao_janelas]].

## Primeiros passos
1. **Insira faixas**: `Ctrl+Q` (áudio) e `Ctrl+Shift+Q` (vídeo).
2. **Importe mídia** pelo painel *Mídia do Projeto* e coloque-a na timeline.
3. **Reproduza**: `Espaço` alterna play/pausa; `J` / `K` / `L` fazem scrub (cada toque extra em `L` ou `J` acelera: 1x, 2x, 4x, 8x, 16x).
4. **Corte**: posicione o cursor e use `S`. Sem seleção, corta os eventos sob o cursor em todas as faixas.
5. **Mova e apare** arrastando: o corpo move, os 7 px de cada ponta aparam, a faixa superior de cada borda ajusta o fade. `Alt` ignora o snapping; `F8` liga/desliga.
6. **Desfaça** com `Ctrl+Z`; cada gesto é um único passo.
7. **Salve** com `Ctrl+S` (formato `.neoveg`). O autosave grava uma cópia de recuperação a cada 2 minutos enquanto houver alterações.

Todos os atalhos: [[atalhos_teclado]]. Projetos aninhados: [[subprojetos_e_abas]]. Regras de edição: [[regras_de_timeline]]. Voltar ao [[Index]].
