2. O QUE É NECESSÁRIO PARA DAR CONTINUIDADE AO PROJETO (PRÓXIMAS ETAPAS)
================================================================================

Para evoluir o **OpenNeoveg 21** de um estúdio híbrido funcional para um NLE de
produção comercial em larga escala mantendo a arquitetura **C# (.NET 10) + TypeScript/JS + Rust + Python**,
os seguintes passos técnicos e componentes são recomendados:

A) CAMADA C# (.NET 10 DESKTOP HOST & INTEGRAÇÃO NATIVA WINDOWS)
--------------------------------------------------------------------------------
1. **Shared Memory Frame RingBuffer (`CoreWebView2.AddHostObjectToScript` / SharedBuffer)**:
   - Hoje o preview em tempo real roda via compositor HTML5 Canvas/WebGL2 e o render
     final roda via FFmpeg. Para reproduzir 4K 60fps ProRes/RAW sem cópia de memória,
     o host C# pode usar `CoreWebView2Environment.CreateSharedBuffer` para mapear
     quadros decodificados em C#/Rust diretamente em texturas WebGL2 no JavaScript.
2. **Suporte Nativo a Controladoras de Hardware ( Mackie Control / USB Jog Wheels )**:
   - Adicionar biblioteca `NAudio.Midi` no projeto C# (`NeovegDesktop.csproj`) para
     ler superfícies de controle físicas e enviar eventos instantâneos ao JS.
3. **ASIO Nativo em C# / Rust (`cpal` ou `NAudio.Asio`)**:
   - Conectar o mixer de áudio a interfaces de áudio profissionais Focusrite/Steinberg
     com latência abaixo de 5ms via driver ASIO direto do executável C#.

B) CAMADA CORRIDORKEY AI & REDES NEURAIS (PYTHON / PYTORCH / ONNX RUNTIME)
--------------------------------------------------------------------------------
4. **Pesos Oficiais do CorridorKey (`CorridorKey_v1.0.pth` — ViT-L + CNN)**:
   - O módulo `python-backend/corridorkey_engine.py` já está integrado ao projeto
     e opera em modo híbrido (Matemática de Desmixagem Linear de Cor em Tempo Real +
     suporte automático ao repositório oficial `nikopueringer/CorridorKey`).
   - Para ativar a inferência neural pesada em placas NVIDIA RTX:
     a) Clonar `https://github.com/nikopueringer/CorridorKey.git` em `./CorridorKey`
     b) Baixar `CorridorKey_v1.0.pth` na pasta `./CorridorKey/checkpoints/`
     c) Instalar `torch torchvision --index-url https://download.pytorch.org/whl/cu124`
     - Ou converter o checkpoint para **ONNX Runtime DirectML (`Microsoft.ML.OnnxRuntime.DirectML`)**
       diretamente no C# para rodar em GPUs NVIDIA, AMD e Intel sem depender de PyTorch!

C) CAMADA DE PLUGINS DE EFEITOS E ÁUDIO (OFX / VST3 / FREI0R / LADSPA)
--------------------------------------------------------------------------------
5. **Host OpenFX (OFX C++ / Rust ABI)**:
   - Implementar carregamento dinâmico de pacotes `.ofx.bundle` em `rust-core` para
     abrir plugins comerciais de terceiros (Contemporary NLE Sapphire, Twixtor, Neat Video).
6. **Host VST3 de 64-bits**:
   - Permitir abrir interfaces gráficas nativas de plugins VST3 (FabFilter, iZotope RX)
     em janelas filhas WinForms do `NeovegLegacy.exe`.

D) CAMADA DE EDIÇÃO AVANÇADA & WORKFLOW BROADCAST (TYPESCRIPT / JS UI)
--------------------------------------------------------------------------------
7. **Edição Multicam (4 a 16 Ângulos Sincronizados por Áudio)**:
   - Dividir o Video Preview em grade 2x2 ou 3x3 permitindo trocar de câmera em
     tempo real com as teclas `1` a `9` durante a reprodução.
8. **Curvas Bézier de Automação e Keyframes no Inspetor**:
   - Expandir o timeline de keyframes do Pan/Crop e de Efeitos com alças de tangente
     Bézier para aceleração suave (*Ease In / Ease Out*).
9. **Importação / Exportação XML, EDL (CMX3600) e AAF (Pro Tools / Resolve)**:
   - Permitir intercâmbio completo de timelines entre OpenNeoveg 21, DaVinci
     Resolve, Adobe Premiere Pro e Avid Pro Tools.
