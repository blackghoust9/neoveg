# Neoveg 1.0.0 — Windows x64

## Funcionalidades

- Timeline NLE para edição não linear de vídeo e áudio.
- Renderização de formas de onda e processamento de áudio pelo núcleo Rust.
- Pipeline de efeitos (FX) nativo em C++.
- Atalhos de teclado inspirados no fluxo de edição do VEGAS.
- Interface escura para o ambiente de edição.
- Sistema centralizado de logs e captura de erros da aplicação.
- Inicialização com sincronização para cache local, reduzindo problemas em unidades sincronizadas ou de rede.

## Distribuição

- Alvo: Windows x64.
