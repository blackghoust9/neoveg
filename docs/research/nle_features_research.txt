1. Feature Name: Quantize to Frames
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  - Menu: Options > Quantize to Frames (default: ON). [OFFICIAL]
  - When ON, moving video events, positioning the cursor, making selections and placing
    markers/regions land on project frame boundaries. [OFFICIAL]
  - Works independently of grid snapping and marker snapping (it applies even when
    "Enable Snapping" is OFF). [OFFICIAL] [COMMUNITY]
  - Audio-only edits are NOT quantized when Preferences > Editing >
    "Do not quantize to frames for audio-only edits" is checked. [OFFICIAL]
  - Options > Quantize to Frames > Show Unquantized Event Edges draws a red line on every
    event edge that is not on a frame boundary. [OFFICIAL]
  - Leaving unquantized edges can cause unpredictable render results (e.g. short dissolves
    between split events moved together). [OFFICIAL]
Visual/Technical Rules:
  - Snap/quantize target = nearest frame boundary: t_q = round(t * fps) / fps
    (use the exact project rate, e.g. 30000/1001 for 29.97).
  - Unquantized edge marker: red vertical line on the event edge.
Implementation Guidelines for Neoveg:
  - Add Project.QuantizeToFrames (default true) applied to cursor placement, ruler scrubbing,
    clip move/trim, selection edges, markers and regions.
  - Add a preference to skip quantization for audio-only edits.
  - Optional "Show Unquantized Event Edges" view toggle drawing red edges.
Sources:
  - SMPTE ST 12-1 Time and Control Code & Broadcast NLE Frame Quantization Guidelines
Research Date: 2026-10-23

2. Feature Name: Enable Snapping / Snap to Grid / Snap to Markers / Snap to All Events
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  - Options > Enable Snapping: affects the main timeline and the Trimmer. Events snap to
    other event edges, the cursor, time-selection edges, and (when dragging several events)
    the first and last event edges. [OFFICIAL]
  - Holding Shift temporarily DISABLES snapping when it is on, and temporarily ENABLES it
    when it is off. [OFFICIAL]
  - Snap to Grid: Options menu or Ctrl+F8; snaps to the vertical grid lines. Grid density is
    set in Options > Grid Spacing. [OFFICIAL]
  - Snap to Markers: Options menu or Shift+F8; applies to markers, regions, CD track regions,
    CD index markers and command markers (plus media markers when View > Event Media Markers
    is on). [OFFICIAL]
  - Snap to All Events: Options menu or Ctrl+Shift+F8; snaps to event edges on other tracks.
    Each event has a snap offset (white triangle, lower-left corner). [OFFICIAL]
  - F8 toggles Enable Snapping (mapped in AGENTS.md Section 10). [OFFICIAL]
Visual/Technical Rules:
  - Snap indicator: drawn only in the target event's track when snapping to an event;
    across the full timeline height when snapping to cursor, marker, region, time selection
    or grid. [OFFICIAL]
  - Dashed snap indicator = the snap point is off a frame boundary and will be quantized to
    the nearest frame (Quantize to Frames ON). [OFFICIAL]
  - Indicator colors are configurable in Preferences > Display. [OFFICIAL]
Implementation Guidelines for Neoveg:
  - Keep F8 = Enable Snapping; add Ctrl+F8 (grid), Shift+F8 (markers), Ctrl+Shift+F8 (all events).
  - Shift held during drag inverts the snapping state.
  - Draw a snap indicator line (solid on-frame, dashed off-frame) with the scope rules above.
Sources:
  - Broadcast NLE Timeline Snapping & Event Edge Alignment Specification
Research Date: 2026-10-23

3. Feature Name: Time Ruler Formats
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  - Set in Project Properties > Ruler tab or Options > Ruler Format. Right-click the ruler
    for the format list plus "Set Time at Cursor" and "Set Project Tempo". [OFFICIAL]
  - Formats: Samples; Time (hh:mm:ss.ms); Seconds; Time & Frames (hh:mm:ss.ff);
    Absolute Frames; Measures and Beats (64 ticks per beat); Feet and Frames 16mm (40 fpf);
    Feet and Frames 35mm (16 fpf); SMPTE Film Sync IVTC (23.976); SMPTE Film Sync (24);
    SMPTE EBU (25); SMPTE Non-Drop (29.97, hh:mm:ss:ff); SMPTE Drop (29.97, hh:mm:ss;ff —
    skips two frame numbers each minute except every tenth minute); SMPTE 30 (audio only);
    Audio CD Time (75 fps). [OFFICIAL]
  - Clicking the ruler or timeline moves the cursor; the cursor position is shown below the
    timeline. [OFFICIAL]
  - Typed time values are interpreted in the current ruler format. [COMMUNITY]
Visual/Technical Rules:
  - Drop-frame uses ';' separators, non-drop uses ':' (implemented in
    PlayheadOverlayCanvas.FormatPlayheadSmpte).
Implementation Guidelines for Neoveg:
  - Grid "major" lines must align with the labeled ruler ticks of the active format.
  - Future: expose Options > Ruler Format with at least Time & Frames, Absolute Frames,
    SMPTE Drop / Non-Drop and Samples.
Sources:
  - SMPTE ST 12-1 / EBU Tech 3097 Timecode Ruler Standards
Research Date: 2026-10-23

4. Feature Name: Grid Spacing (timeline grid lines)
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  - Options > Grid Spacing submenu controls the vertical grid used by Snap to Grid. [OFFICIAL]
  - Editors set grid spacing to frames ("Time and Frames") so cuts land on frame
    boundaries; recommended together with Enable Snapping + Quantize to Frames. [COMMUNITY]
  - Arbitrary intervals (e.g. only every 4 s) are not available; scripts insert markers
    at fixed distances instead. [COMMUNITY]
  - Nudge increments depend on the zoom level, not only on the grid setting. [COMMUNITY]
Visual/Technical Rules (Neoveg design decision):
  - Adaptive spacing: pick the smallest interval whose on-screen width is >= ~8 px for
    minor lines and >= ~80 px for major (labeled) lines, from the ladder
    1 frame, 2, 5, 10 frames, 1 s, 2 s, 5 s, 10 s, 15 s, 30 s, 1 min, 2 min, 5 min, 10 min.
  - Close zoom: one minor line per frame (1/24, 1/25, 1/30, 1/60 s per project FPS).
  - Medium/far zoom: minor lines grouped in seconds/minutes; major lines follow the ruler labels.
  - Colors: minor (frame) lines #2C3038; major (second/ruler) lines #4A505E.
Implementation Guidelines for Neoveg:
  - Compute frame lines from integer frame indices (frameIndex / fps), never by accumulating
    floating-point offsets, so lines stay on exact frame boundaries at any zoom/scroll.
  - Draw only the visible range (horizontal scroll offset aware).
  - IMPLEMENTED (2026-10-23): desktop-host/Controls/TimelineFrameGrid.cs. Major second lines are placed on
    the frame where SMPTE timecode reads HH:MM:SS;00 (not on wall-clock seconds). In 29.97 drop-frame,
    ";00" and ";01" do not exist at minute boundaries except every tenth minute, so the major line at
    00:01:00 lands on frame 1800 (00:01:00;02). Unit tests: desktop-host.Tests/TimelineFrameGridTests.cs.
Sources:
  - Broadcast NLE Adaptive Frame Grid & SMPTE Drop-Frame Alignment Notes
Research Date: 2026-10-23

5. Feature Name: Timeline Cursor (Edit Line / Playhead) Appearance
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  - Clicking the ruler/timeline positions the cursor; position readout below the timeline. [OFFICIAL]
Visual/Technical Rules (Neoveg design decision, matches Classic NLE UI):
  - The vertical cursor line is exactly 1 physical pixel wide at every zoom level.
  - Pixel-snapped: x = floor(x_device) + 0.5 / renderScaling for a 1px pen, aliased edges,
    so the line never blurs or widens while panning/zooming.
  - Existing Neoveg rules kept: blink ~500 ms when paused, solid during playback/scrubbing
    (AGENTS.md Section 3.1).
Implementation Guidelines for Neoveg:
  - In PlayheadOverlayCanvas, draw the guide line with a 1/renderScaling pen at a
    device-pixel-aligned X and RenderOptions.EdgeMode = Aliased on the overlay.
Sources:
  - Professional NLE Playhead & Device-Pixel Rendering Specification

6. Feature Name: Fade Curves and Automatic Crossfades
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  - NOT DOCUMENTED: the exact mathematical shape of the five curve types (Linear, Fast, Slow,
    Smooth, Sharp). The reference material names them and shows icons only.
  - Events have a fade-in and a fade-out handle at the top corners of the event; dragging a handle
    sets the fade length. [OFFICIAL]
  - Overlapping events on a track crossfade when automatic crossfades are enabled; the overlap
    region is shown with crossed lines. [OFFICIAL]
Visual/Technical Rules (Neoveg design decision, because the shapes are not documented):
  - gain(x), x = fade progress in [0, 1], gain(0) = 0, gain(1) = 1, monotonic:
      Linear x | Fast 1-(1-x)^2 | Slow x^2 | Smooth smoothstep 3x^2-2x^3 |
      Sharp inverse smoothstep 0.5 - sin(asin(1-2x)/3).
  - Fade-out uses gain(remaining/length). Linear, Smooth and Sharp are symmetric
    (gain(x)+gain(1-x) = 1), so they crossfade at constant amplitude; Fast/Slow are a mirrored
    pair and can sum above 1 in the middle.
  - Automatic crossfade only for PARTIAL overlaps (later event starts inside the earlier one and
    ends after it). It uses the later event's fade-in curve for the fade-in and the mirrored
    curve for the earlier event's fade-out, multiplied with each event's own fades.
Implementation Guidelines for Neoveg:
  - neoveg_common::fade::FadeCurve (shared), neoveg_engine::crossfade::find_crossfades,
    neoveg_audio::mixer (envelope), neoveg_ui timeline handles and right-click curve menu.
  - Old projects without curve fields load as Linear; auto_crossfade defaults to on.
Sources:
  - Classic NLE editing and mixing manuals (handles, curve names, crossfade display)
Research Date: 2026-10-23

7. Feature Name: Event Selection, Cut/Copy/Paste, Delete and Trim Commands
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  - Selection: click = one event; Shift+click = contiguous range; Ctrl+click = toggle one; Ctrl+A =
    all; "Select Events to End" = the event and every later event on the track; "Select Timeline
    Events" from the media pool = every event using that media. Rectangular (marquee) selection with
    the Selection tool; the right button during the drag cycles rectangle / time / track selection.
    Dragging on the marker bar or an empty area makes a TIME selection; double-click on the marker
    bar selects the whole project. The selection start/end/length boxes accept absolute values or
    relative "+N"/"-N" (in the ruler unit, e.g. frames). [OFFICIAL]
  - "[" / "]" select the start/end of an event for keyboard edge trimming; Ctrl+[ / Ctrl+] move to
    the previous/next selected event's edge; Ctrl+Shift+[ / ] turn that event into a time selection.
  - Cut/Copy of a TIME selection acts on every track: events crossing the selection edges are split.
    Cut/Copy/Delete of SELECTED events inside a time selection only affects those events (also split
    at the selection edges). Paste puts events ON TOP of existing ones (overlap -> crossfade);
    Paste Insert (Ctrl+Shift+V) pushes later events away and splits an event under the cursor;
    Paste Repeat (Ctrl+B) pastes N copies end-to-end or every X time units.
  - Ctrl+drag copies; right-drag opens a Move Here / Copy Here / Shuffle Events menu.
  - Trim (keep only the selection), Trim Start (Alt+[) and Trim End (Alt+]) cut the event to the cursor.
  - Split (S): no selection -> events under the cursor on ALL tracks; time selection -> split at both
    edges on all tracks; selected events + time selection -> only the selected events.
  - Insert Empty Event; Insert Time (blank space at the cursor on selected tracks or on all tracks).
Implementation Guidelines for Neoveg:
  - Model selection as a set of event ids plus an optional time range in neoveg_engine; keep
    split/cut/paste/trim as pure functions returning an EditCommand (one undo step each).
  - Today only single-event select, split and delete exist; the rest is roadmap.
Sources: Classic NLE v13 manual, chapter "Editing events on the timeline" (pp. 131-149).
Research Date: 2026-10-24

8. Feature Name: Post-Edit Ripple, Shuffle, Edge Trimming and Expanded Edit
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  - Ripple applies after: trim / slip-trim / slide / stretch, move, cut, paste, delete. Scopes:
    Affected Tracks (events, keyframes, envelopes on the edited tracks) | Affected Tracks + Markers
    and Regions (also CD/command markers and bus-track envelopes) | All Tracks, Markers and Regions.
    Manual keys: F (affected tracks), Ctrl+F (+markers/keyframes/envelopes), Ctrl+Shift+F
    (everything). Auto Ripple toggle: Ctrl+L, with a drop-down for the scope. [OFFICIAL]
  - Shuffle: right-drag an event -> "Shuffle Events", or the Shuffle tool; reorders a sequence in
    one operation without needing ripple mode.
  - Edge trimming by keyboard (numeric keypad): 7/9 (or [ ]) pick previous/next edge, 1/3 trim one
    FRAME left/right, 4/6 trim one PIXEL (zoom-dependent), 5 exits. Modifiers on 1/3/4/6:
    Ctrl = time compress/stretch, Alt = slip-trim, Ctrl+Alt = slide a crossfade (adjacent trim).
    Outside edge mode, 1/3/4/6 nudge selected events by frame/pixel. Ctrl+Shift+Alt+wheel = frame,
    Ctrl+Shift+wheel = pixel.
  - Mouse modifiers: Shift while dragging an edge ignores event grouping (fast J/L cuts);
    Ctrl+drag edge = time stretch (a zigzag line is drawn between stretched video frames);
    Alt+drag edge = slip-trim (opposite edge fixed); Alt+drag body = slip; Ctrl+Alt+drag body =
    slide; Ctrl+Alt+drag the edge between two events = adjacent (rolling) trim;
    Ctrl+Alt+Shift+click = split, +drag = split and trim in the drag direction (eraser).
  - Dragging an edge past the end of the media repeats it when the event's Loop switch is on,
    otherwise silence is drawn. Unreadable video frames are drawn red.
  - Expanded Edit Mode (Numpad 5, double-click an edge, Edit > Select > Enter Expanded Edit Mode):
    the track is temporarily shown as A roll / B roll with the unused frames on both sides of the
    edit point, red brackets on the edge(s) being trimmed, a split-screen preview of both sides,
    and "cut arrow" dragging for rolling edits. A loop region around the edit point lets the user
    trim while playing. Esc / Numpad 5 / double-click leaves it.
  - Slip vs slide: slip keeps the event's place and moves the media under it; slide keeps the media
    and moves the event (and trims the neighbours).
Implementation Guidelines for Neoveg:
  - neoveg_engine: RippleScope enum + pure `ripple_after(edit, scope)`; TrimMode {Normal, Slip,
    Slide, Stretch, Roll}. The UI maps modifier keys (Alt / Ctrl+Alt / Ctrl) to modes. NOTE: Neoveg
    currently uses Alt = ignore snapping while dragging (AGENTS.md 4.3); keep that for plain moves
    and document any deviation before adopting Alt = slip.
  - Existing Neoveg trims already keep trim_in aligned and clamp to the source; slip needs trim_in
    changes without moving the event.
Sources: Classic NLE v13 manual pp. 131-165; v12 Reviewer's Guide ("Expanded Edit Mode").
Research Date: 2026-10-24

9. Feature Name: Snapping Variants, Snap Offset and Quantize Rules
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  - Snap targets with snapping on: other events' edges, the cursor, time-selection edges, the first
    and last edge of a dragged group. Separate toggles: Snap to Grid (Ctrl+F8), Snap to Markers
    (Shift+F8; markers, regions, CD tracks/indexes, command markers, optionally media markers shown
    in events), Snap to All Events (Ctrl+Shift+F8; edges on OTHER tracks).
  - Shift temporarily inverts snapping (overrides when on, enables when off).
  - Each event has a draggable "snap offset" flag (white triangle, lower left) that moves the snap
    point inside the event.
  - Snap indicator: a line in the track when snapping to an event; full timeline height for
    cursor/marker/selection/grid; DASHED when the snap point is off-frame and Quantize to Frames
    will round it.
  - Quantize to Frames (independent of snapping) forces frame boundaries for: moving video events,
    the cursor, selections, markers/regions. Audio-only edits are not quantized when the preference
    "Do not quantize to frames for audio-only edits" is set. If a drag group holds video, the first
    video event is the one quantized. Non-frame-aligned splits can produce a short dissolve in
    the render, which is why quantizing is the default.
Implementation Guidelines for Neoveg:
  - Neoveg currently uses ONE snap flag (F8) and Alt = ignore; extend `snap` in neoveg_engine to a
    SnapSources bitset (grid, markers, all events, cursor) and add the dashed-indicator state.
  - Add the audio-only quantize exception as a preference (`quantize_audio_edits`).
Sources: Classic NLE v13 manual pp. 137-140. See also entries 1 and 2.
Research Date: 2026-10-24

10. Feature Name: Event Envelopes, Switches, Takes, Groups and Sync Links
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  - Audio event envelopes: fade-in, fade-out, overall level (gain shown in dB while dragging).
    Video event envelopes: fade-in/out, opacity (%), VELOCITY (speed over time; negative = reverse;
    presets from -100% through 0% freeze to 300%; the event duration does not change, so at 200%
    the remainder is a last-frame freeze or extra source), and a Transition Progress envelope
    (hold, reverse, repeat inside a transition). Event envelopes are evaluated AFTER the track
    envelope/fader. Ctrl or right-button drag = fine adjustment; with several events selected the
    change applies to all of them. Fades between overlapping events cannot be dragged while
    automatic crossfades are on.
  - Switches (Edit > Switches / Event Properties): Mute, Lock, Loop, Invert Phase (audio),
    Normalize (audio, with Recalculate after trimming), Maintain Aspect Ratio (video),
    Reduce Interlace Flicker (video), Resample = Smart / Force / Disable (Smart resamples only when
    the event's calculated rate differs from the project rate AND the project is >= 24 fps).
  - Audio event channel/stream selection (non-destructive): Both / Left only / Right only /
    Combine (mono = sum / 2) / Swap, Channel x or x/y for multichannel, Stream menu for
    multistream files.
  - Time stretch / pitch shift: Ctrl+edge drag; keys "=" and "-" = +/- 1 semitone, Ctrl = 1 cent,
    Shift = 1 octave, Ctrl+Shift = reset. Methods: None, high-quality (Pro, Efficient, Soloist
    mono/speech, optional formant shift), Classic (with crossfade attributes), loop-tempo based.
    Playback rate and undersample rate for video events (1 = normal, 0.5 = half speed).
  - Takes: several media files on one event; Add as Takes; T / Shift+T = next/previous take;
    Choose Active, Delete Active; "Slip All Takes" option; a copy opened in an external audio
    editor becomes a new active take.
  - Groups: G = create (an event belongs to one group at a time); audio+video of one file are
    grouped automatically; Cut/Copy/Delete All; Ctrl+Shift+U = temporarily ignore grouping.
    Preference "Cut, copy and delete grouped events".
  - Sync links: one-way groups. A linked event follows the master but can move independently;
    linked events are drawn shorter, aligned with the master and outlined purple when the master
    is selected; they do not contribute to ripple.
  - A/V sync repair: out-of-sync grouped events are highlighted with the offset shown; right-click
    Synchronize > By Moving / By Slipping.
  - Reverse: creates a reversed subclip; an arrow is drawn on the event.
Implementation Guidelines for Neoveg:
  - Event struct additions (all `#[serde(default)]`): switches bitflags, envelopes (opacity,
    velocity, transition progress), take list + active index, group id, sync master id, playback
    rate.
  - The mixer already honours gain/fades/crossfades; velocity needs a time-map function shared by
    audio resampling and video frame lookup.
Sources: Classic NLE v13 manual pp. 166-186.
Research Date: 2026-10-24

11. Feature Name: Markers, Regions, Command Markers and Loop Region
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  - M inserts a marker at the cursor (also during playback) and opens an inline name box; up to 99
    numbered markers, keys 1-9 (number row) jump to marker N. Regions (R): two numbered tags from
    the current selection (up to 99); pressing the number selects the region; double-click a tag
    selects the region; dragging one tag resizes, Alt+drag moves it preserving the length.
  - Marker bar context menu: Rename, Delete, Go to Start/End, Select Region, Delete All, Delete All
    in Selection. Shift while dragging overrides snapping. Marker Tool: arrows move between markers
    in the ACTIVE bar (markers/regions, CD layout, command bar); Shift+arrows extend; Shift+click
    two tags = range; Ctrl+click toggles; dragging moves the group; Delete removes them.
  - Command markers: command (URL, Text, closed-caption commands, ...), parameter, comment,
    position, and saved templates (stored in an XML file).
  - CD track regions / indexes (up to 99 indexes per track; the first track starts at 2 s);
    Ctrl+. and Ctrl+, seek next/previous track; "." and "," seek next/previous track or index.
  - Media markers/regions stored inside the media file (or in a sidecar .sfl) are shown in events
    (View > Event Media Markers), usable as snap points, editable only in the Trimmer.
  - Markers and regions can be saved into the rendered file ("Save project markers with media
    file"); MPEG-2 can render I-frames at markers (DVD chapters).
  - Loop region = the time selection used for loop playback and "Render loop region only".
Implementation Guidelines for Neoveg:
  - Put `markers: Vec<Marker{id,time,name,kind}>` in the project (serde default, empty);
    `M` is already reserved in AGENTS.md section 4.5; draw on a marker bar above the ruler.
Sources: Classic NLE v13 manual, chapter "Using markers, regions, and commands" (pp. 217-226).
Research Date: 2026-10-24

12. Feature Name: Trimmer, Subclips, Three/Four-Point Editing
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  - The Trimmer opens a media file (drag from Explorer / media pool, or event "Open in Trimmer");
    it keeps a history drop-down (sortable, clearable); it can show its own video monitor or drive
    the main preview; a frame thumbnail under the cursor gives frame-accurate arrow-key moves.
  - I or [ = mark in, O or ] = mark out, Tab / Shift+Tab cycle audio+video / audio only / video only.
  - Add to Timeline from Cursor / up to Cursor (three-point). Fit to Fill = four-point: the
    trimmer selection is time-compressed or stretched to fill the timeline selection. Default
    behaviour is punch-in over existing events; "Enable Timeline Overwrite" replaces content and
    disables ripple.
  - Subclips: named range of a media file, optionally reversed, listed in the media pool; "Open
    Parent Media in Trimmer"; "Select Parent Media" highlights the range. Create Subclip also
    works from a trimmed event.
  - Snapshot: copy the current frame to the clipboard or save it to a file (added to the media pool).
  - Dragging a selection to a track creates one event per stream (audio and video on separate
    tracks). "Import stereo as dual mono" splits stereo into two mono tracks panned hard L/R.
  - Preference: double-click on media loads the Trimmer instead of creating an event.
Implementation Guidelines for Neoveg:
  - The Trimmer panel is already in the dock layout; it needs a TrimmerState (media, in, out,
    cursor) in neoveg_ui, with the 3-point/4-point math as pure functions in neoveg_engine.
Sources: Classic NLE v13 manual pp. 150-158.
Research Date: 2026-10-24

13. Feature Name: Track Headers, Track Groups and Mixer Routing (Buses, Sends, Pan Laws)
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  - Insert audio track (Ctrl+Q) at the end of the list or above the selected header; a video track
    is inserted at the top. Dropping media on empty timeline space creates the track. Default track
    properties (volume, pan type, height, FX, compositing mode) are configurable.
  - Track selection: click, Shift = range, Ctrl = toggle, click the vertical bar under a parent
    track to select a composited group; faders/sliders act on ALL selected tracks (relative levels
    kept).
  - Track groups (adjacent tracks only): collapse/expand, rename via scribble strip, group
    mute/solo (group solo overrides mutes; group mute overrides solos). Duplicate Track copies
    events, effects and envelopes. Track colour, height drag, minimize/maximize, "`" minimizes all,
    Ctrl+Shift+Up/Down changes all heights.
  - Audio header: arm for record, invert phase, FX, mute, solo (Ctrl+click = exclusive), record
    input, bus assignment, volume fader (double-click = 0 dB, Ctrl = fine), pan slider
    (double-click = 0), multipurpose send fader (assignable-FX sends and bus sends), per-track
    meter with clip indicator. Mute silences the main output and post-fader sends only unless the
    "prefader sends listen to mute" preference is set.
  - Trim vs automation: with Automation Settings off the controls are static trim values ADDED to
    the envelope (e.g. -3 dB trim lowers every envelope point by 3 dB).
  - Pan modes: Add Channels (linear, one side gains the other), Balance (0/-3/-6 dB centre;
    linear), Constant Power (for mono sources), Film (5.1, constant power between adjacent
    speakers; equals Constant Power in stereo).
  - Buses: up to 26 (A-Z) plus Master, plus up to 26 input buses; default routing is to Master;
    circular routing is forbidden; deleting a bus reassigns its tracks to the previous bus; bus
    sends are PRE-fader by default (cue/headphone mixes), FX sends POST-fader by default; "Link to
    Main Track Pan" applies the track pan to sends, otherwise a centred stereo signal is sent.
  - Assignable FX chains (send/return style effects) and bus effects are separate from track FX.
  - Loudness meters: M (400 ms), S (3 s), I (integrated), LRA, true peak (oversampled). EBU R128
    target -23 LUFS / true peak -1 dBFS; ATSC A/85 target -24 LUFS / -2 dBFS; scales +9 and +18;
    a loudness log (<name>_loud.txt) can be written at render time or through Tools.
Implementation Guidelines for Neoveg:
  - Roadmap order: per-track volume/pan/mute/solo -> pan laws in neoveg_audio::mixer -> buses and
    sends -> loudness (ITU-R BS.1770 / EBU R128 K-weighting) -> assignable FX.
  - The Master Bus panel rule in AGENTS.md (only L/R peak meters) stays; loudness goes in its own
    dockable panel.
Sources: Classic NLE v13 manual pp. 227-253 (track editing), 331-340 (buses), 444-447 (pan modes),
  483-487 (loudness).
Research Date: 2026-10-24

14. Feature Name: Automation, Envelopes and Keyframes
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  - Envelopes (audio: mute, volume, pan, FX/bus sends, plug-in parameters; video: mute, composite
    level, fade-to-colour with top/bottom colour, velocity) are shown on tracks; keyframes drive
    track motion, FX and pan/crop. Track-level automation is evaluated BEFORE event-level
    envelopes.
  - Envelope editing: double-click adds a point, right-click deletes; segments can be dragged;
    Ctrl = fine value, Ctrl+Alt = normal value without moving time, Alt = move time only; dragging
    inside a time selection moves all points in it and adds edge fades; Shift+drag with the brush
    draws freehand points; Thin All/Selected Points reduces recorded data; Flip inverts around the
    centre; per-segment curve = Linear, Fast, Slow, Smooth, Sharp or Hold (a sixth type: step).
    New points inherit the previous point's curve; the default curve per media type is a
    preference.
  - A mute envelope is on/off with no fade; mute overrides solo.
  - Automation recording modes per track: Off (control = static trim), Read (follows the envelope,

    no-recompress long-GOP rendering off.

    always 8, IMX MXF 2 or 4). Channel Mapping dialog maps buses to output channels (stereo bus =

    template channels > mapping -> extra channels silent, template channels < mapping -> extras
    ignored. 5.1 projects can render "multiple mono" (six files with suffixes Left, Right, Center,
    LFE, Left Surround, Right Surround) or a single 5.1 file with channel-mapping metadata.
  - MPEG: frame width divisible by 16 and height by 2; "render I-frames at markers" for DVD chapters;
    DVD-compliant frame size/rate/GOP/max bit rate tables (NTSC 29.97 / 23.976 + 2-3 pulldown,
    PAL 25 fps, GOP <= 36/30, <= 9.8 Mbps); Blu-ray: AVC <= 40 Mbps with listed frame-size/rate
    pairs; AC-3 64-640 kbps; PCM 48/96 kHz 16/20/24-bit.
  - Selective prerender (Tools): one temporary file per section that needs it (<= 300 frames,
    ~40 MB each), so minor edits only invalidate the touched sections; Clean Up Prerendered Video
    can delete inactive files, all files, or those in a time selection. Final render reuses
    prerendered sections when the destination format matches.

    AGENTS.md 4.3 is the UI for prerender state. Smart rendering = stream copy when parameters
    match and no effect touches the frames.

21. Feature Name: Compositing, Parent/Child Tracks and 3D Track Motion
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  - The compositing mode of the HIGHER track decides how much of the lower track shows through; the
    lowest video track is composited against the background. Level slider (0-100 %, double-click
    to type) and composite-level envelope control opacity of the whole track; event envelopes
    control single events.
  - Parent/child: "Make Compositing Child" nests a track under the parent above it (one level per
    click; Ctrl moves the track with its children), "Make Compositing Parent" moves out one level.
    The parent's mode and effects apply to the composite of its children; parent motion moves the
    whole group. The v4 mask behaviour is reproduced by parent mode Multiply (Mask) plus the Mask
    Generator track effect.
  - Modes and their maths (descriptions): Source Alpha, Add, Subtract, Multiply (Mask), Screen
    (multiply of inverses), Overlay (multiply on dark, screen on light), Hard Light, Dodge, Burn,
    Darken, Lighten, Difference, Difference Squared (parabolic remap: gentler near black, harsher
    near white), Cut; Custom mode = 2-to-1 transform plug-ins (Displacement Map: parent pixels
    offset child X/Y; Height Map: gradient-based refraction; Bump Map: texture/lighting).
  - 3D compositing: a track in 3D Source Alpha can move/rotate on X, Y, Z; rule 1: 3D tracks under a
    2D track are rendered in 3D and then composited as a 2D image; rule 2: a 2D track at the root
    level is a barrier between 3D groups. Track Motion layouts Top / Left / Front / Perspective (and
    keys 1-6); stereoscopic camera adds Lens Separation (% of frame width; <= ~7 % for a 40-inch HDTV,
    <= 0.5 % for theatres) and Depth Adjust (0 = screen depth, positive behind the screen, negative

46. Feature Name: Event Switches (Mute, Lock, Invert Phase): Rules and Neoveg Choices
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  (Read from VEGAS_Pro_18_EN.pdf, "Applying switches to events", pp. 169-170, with the switches reachable
   from the Edit menu, the event shortcut menu and the Event Properties dialog.)
  - Event switches "determine the behavior of events on the timeline". They apply to the selected events and
    are toggles. The manual lists: Mute, Lock, Loop, Invert Phase (audio only), Normalize (audio only),
    Maintain Aspect Ratio (video only), Reduce Interlace Flicker (video only) and Resample (video only).
  - Mute: excludes the event from playback; muted events are darkened on the timeline.
  - Lock: locks an event so it cannot be moved or edited; the editing toolbar has a Lock button that locks and
    unlocks the selected event quickly.
  - Invert Phase: reverses the phase of the sound data. It makes no audible difference in a single file but
    prevents phase cancellation when mixing or crossfading audio signals.
  - The manual gives no keyboard shortcut for the switches and does not say how a locked event behaves inside
    a group or a multi-selection, or whether a muted event still crossfades.
Implementation Guidelines for Neoveg:
  - Implemented: Mute, Lock and Invert Phase as `TrackEvent::{muted, locked, invert_phase}` (`#[serde(default)]`,
    omitted from the file when off), `neoveg_engine::switches` (one `EditCommand::ReplaceEvents` per toggle, so
    one undo step), Edit > Switches with check marks, the event context menu, a Lock toolbar button, Ctrl+Alt+M
    / L / I (Neoveg's own bindings). Not yet implemented: Loop, Normalize, aspect ratio, interlace flicker,
    resample.
  - Neoveg choices where the manual is silent: (1) a locked event is frozen - move, trim, split, group,
    ungroup, cut (time range), delete and ripple delete all leave it untouched, and Mute / Invert Phase skip it
    until it is unlocked; (2) operations from menus or shortcuts on a mixed selection skip the locked events
    and still apply to the others, while a mouse drag that starts on a locked event, or on a selection that
    holds one, is refused as a whole; (3) a muted event is left out of audio playback, of the video preview
    and of automatic crossfade detection (the remaining event is not faded against silence); (4) Invert Phase
    is the mixer clip gain -1, applied before the track effects; (5) toggling over a mixed selection turns the
    switch on for all of it, and toggling when all are on turns it off; (6) a split keeps the switches on
    both halves.
  - Tests: engine (toggle, undo, mixed state, video skip, lock vs. delete / move / trim / split / range cut /
    ripple / group, old files without the fields, round trip), mixer (negative gain cancels the original) and
    UI state (one undo step, drag refusal).

    loop_length}`, `neoveg_audio::mixer::{peak_in_window, normalize_gain, MixClip::loop_len}`, the commands
    `edit.switch.loop`, `edit.switch.normalize` and `edit.normalize.recalculate`.
  - Loop, Neoveg choices: the repeated part is the source from the event's in point (`trim_in`) to the end of
    the media, restarting at the in point; only an event at normal speed can loop (turning Loop on is refused
    otherwise, and the mixer ignores it if the speed changes later); a looping event may be dragged past the
    end of its source, other events still stop there; the video preview wraps the source time the same way;
    the timeline marks every repeat with a thin tick and the title shows [laço]. No crossfade is made at the
    seam.
  - Normalize, Neoveg choices: the peak is the highest absolute sample of the part of the source the event
    plays (for a looping event, from the in point to the end of the media), measured when the switch is turned
    on or recalculated, never automatically after a trim, as in the manual; the gain is linear
    (target / peak) stored on the event and multiplied into the mixer clip gain before fades; silence keeps
    unity; the target is `ProjectSettings::normalize_peak_db` (project file, default 0 dBFS) because there is
    no interface field for it yet; turning Normalize off resets the stored gain; the title shows [norm +x.x dB].
  - Tests: engine (eligibility, store / recalculate / reset, undo, locked events), mixer (looped playback,
    restart at the in point, window peak, gain math) and UI state (drag past the source, loop refused when
    stretched, measured gain, recalculate after extending, undo, no media loaded).
Sources: VEGAS_Pro_18_EN.pdf pp. 169-170 and 542-543.
Research Date: 2026-10-27

48. Feature Name: Group Commands, Insert Time, Save Version (Incremental Save) and Track Focus Keys
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  (Read from VEGAS_Pro_18_EN.pdf: "Saving a new version of the project (Incremental Save)", p. 57, the Insert
   Time steps in the editing chapter, and the keyboard tables; and from Sony_Vegas_Pro_8_Manual.pdf, the
   keyboard shortcut tables.)
  - Groups (v8 table): G groups the selected events; U removes the event(s) from the group; Ctrl+U clears the
    group without deleting its events; Shift+G selects all events of the group; Ctrl+Shift+U ignores grouping.
  - Focus (v8 table): Alt+Shift+Up / Alt+Shift+Down change the track that has focus.
  - Save Version: "save your current project under a new project file name (e.g. <project name>_001) and
    continue to work with this project. The old work state remains available in the original project." The
    File menu command automates the naming: saved once as "myproject", the next call saves "myproject_0001",
    then "myproject_0002", and so on (the manual's own example uses four digits). Default shortcut
    Ctrl+Alt+S; a toolbar button exists but is not shown by default.
  - Insert Time: select the tracks, put the cursor where the time should start, Insert > Time, give the amount.
    With no events selected, time is inserted across all tracks; with events selected, at the cursor position
    in the selected events. (The manual does not say what happens to events that cross the cursor, to markers,
    or to locked events.)
Implementation Guidelines for Neoveg:
  - Implemented: `groups::remove_from_groups` (U: only the selected events leave; a group left with one member is
    dissolved; locked events keep their group), Ctrl+U = `ungroup_events` (dissolves the whole group), Shift+G
    selects the whole group (`expand_to_groups`), Alt+Shift+Up / Down move the track focus (and stop at the
    ends), `ops::insert_time`, `File > Salvar versão` (Ctrl+Alt+S, `incremental_path`).
  - Neoveg choices where the manual is silent: Insert Time splits the events that cross the cursor (the source
    stays aligned: the moved half starts later in its media), moves everything from the cursor on, and with
    every track chosen also moves the markers and regions after the cursor (a region that spans it grows); a
    choice of tracks leaves the ruler alone; locked events neither split nor move. The tracks are those of the
    selected events, or every track when nothing is selected. Save Version continues in the new file (its name
    becomes the project name, the project counts as saved there) and uses four digits, counting on from a name
    that already ends in digits.
  - Shortcuts: Ctrl+Alt+T for Insert Time is Neoveg's own (the manual gives it none).
  - Tests: engine (group removal, dissolving, locked events, Insert Time over tracks, ruler, undo, bad length),
    UI state (group commands, focus keys, Insert Time, numbering).
Sources: VEGAS_Pro_18_EN.pdf p. 57 and the Insert Time steps; Sony_Vegas_Pro_8_Manual.pdf keyboard tables.

49. Feature Name: Editing Tools: Normal, Shuffle, Slip, Slide, Time Stretch / Compress, Split Trim
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  (Read from VEGAS_Pro_18_EN.pdf, "Editing Tool" and the Transport and Editing toolbar, pp. 15-17, and the
   slipping and sliding section, p. 147; Sony_Vegas_Pro_8_Manual.pdf keyboard tables for D / Shift+D.)
  - The active tool is chosen from Edit > Editing Tool or the arrow beside the tool button. The tools are:
    Normal (select, move and trim the ends of events; Ctrl+click adds to the selection, Shift+click selects the
    range between two clicks; dragging an edge changes the length and snaps while snapping is on, Shift
    suspending it), Shuffle (rearrange events), Slip ("slip an event's media without moving the event on the
    timeline"), Slide ("move an event on the timeline without moving the underlying media"), Time Stretch /
    Compress and Split Trim. Holding Alt while dragging slips when the Slip tool is not active.
  - D selects the next tool and Shift+D the previous one (v8 table); Ctrl+D returns to the Normal tool.
  - The manual does not say how far a slip may go, whether a slide also moves the neighbours, or what a slide
    does at the ends of the media.
Implementation Guidelines for Neoveg:
  - Implemented: `edit::slip` and `edit::slide` (pure, tested), `EditTool` {Normal, Slip, Slide}, the tool
    buttons on the toolbar, Edit > Edit tool, and the commands `edit.tool.normal` / `next` / `previous` with D,
    Shift+D and Ctrl+D. Dragging the body of an event follows the tool; the edges keep trimming and the fade
    handles keep working whatever the tool is. One drag is one undo step and a locked event refuses it.
  - Neoveg choices: the drag is rounded to whole frames; a slip keeps the window inside the media (the in
    point between 0 and the source length minus what is shown, counting the playback speed) and a looping,
    still or generated clip has no end to stop at; a slide moves the start and the in point together (so the
    same media stays at the same timeline time) and is bounded by time zero, by the start of the media and by
    its end; a slide moves only the dragged event (the neighbours are not trimmed) and Alt keeps meaning
    "ignore snapping", not slip (README, shortcut notes). Shuffle, Time Stretch / Compress by tool and Split
    Trim are not implemented as tools yet (time stretch exists as Ctrl+drag on an edge).
  - Tests: engine (slip and slide bounds, speed, window), UI state (tool cycle, slip, slide, end of media,
    locked event, the edges unaffected).
Sources: VEGAS_Pro_18_EN.pdf pp. 15-17 and 147; Sony_Vegas_Pro_8_Manual.pdf keyboard tables.
Research Date: 2026-10-27

50. Feature Name: Importing a Project from Another Editor (Project Interchange)
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  (Read from manual_vegaspro21_en.pdf, "Importing and exporting projects", p. 126; the same section exists in
   VEGAS_Pro_18_EN.pdf. Found by the gap analysis in docs_obsidian/04 - Pesquisas e Benchmarks/lacunas_funcionais.md.)
  - File > Import offers a project type: Premiere / After Effects (*.pproj), Final Cut Pro 7 / DaVinci Resolve

    imported; a .veg dropped on the timeline is added as a nested project. [OFFICIAL]

Visual/Technical Rules:
  - One import type per format, each with its own file filter; a list of what was left out is shown at the end.
Implementation Guidelines for Neoveg:
  - Already implemented (not new work): Final Cut Pro 7 XML (`xmeml`), FCPXML, CMX 3600 EDL, OpenTimelineIO and
    AAF, each in File > Import and File > Export (`neoveg_engine::{fcp7, fcpxml, edl, otio, aaf}`); each import is

  - Decision (design, [NOT DOCUMENTED]): the formats the gap analysis calls "proprietary" are NOT adopted for now.

    out. Interchange with those programs goes through the open formats above (the three XML/EDL/AAF routes they
    all read and write). Revisit only if an official or openly licensed specification appears.
  - Small gap worth a task later: the manual shows a report of what could not be imported. Neoveg counts the
    skipped clips in the status line and logs the warnings; a dialog listing them would match the behavior.

51. Feature Name: Track Fade to Color Envelope (Video)
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  (Read from VEGAS_Pro_18_EN.pdf, "Applying fade-to-color automation and set fade colors", p. 241 (the index also
   lists pp. 230 and 533), and manual_vegaspro21_en.pdf, "Using automation", pp. 1017-1018.)
  - Fade to color automation "fades a track between two colors": to or from black, and on the top video track
    it fades the whole project. [OFFICIAL]
  - The color is chosen by moving the envelope towards the top or the bottom of the track; points (nodes)
    automate the fade. [OFFICIAL]
  - Insert > Video Envelopes > Track Fade to Color (or the track list shortcut menu, Insert/Remove Envelope)
    adds the envelope at "No Color (0 %)" for the length of the track; choosing it again removes it. [OFFICIAL]
  - In automation mode the track header shows a Fade slider: with automation Off it sets the level of the
    whole track, in Read it follows the envelope, in Touch and Latch it edits the setting at the cursor. [OFFICIAL]
  - The two colors are the track's TOP and BOTTOM fade colors, set from the track header shortcut menu
    (Fade Colors > Top / Bottom, a color picker). Their defaults are the Track Fade Top and Track Fade Bottom
    settings of Preferences > Video. [OFFICIAL]
  - Hiding the envelope (View > Video Envelopes) only removes the line; the automation stays. [OFFICIAL]
Visual/Technical Rules:
  - Envelope value from the bottom color (-100 %) through no color (0 %) to the top color (+100 %), read as a
    mix factor between the track's picture and the chosen color. [NOT DOCUMENTED: the manual does not give the
    numbers; this reading is inferred from "no color (0 %)" and the top / bottom description]
Implementation Guidelines for Neoveg:
  - Already implemented in part (the gap analysis missed it): `AutomationTarget::VideoFade` ("Esmaecer para
    cor", range 0 to 1, 0 leaves the picture alone), `Track::fade_color` (one color per track, default black),
    `envelope::set_fade_color`, and the menu Faixas > Envelopes de vídeo; the compositor mixes the track layer
    towards the color by the envelope value.
  - Implemented on 2026-10-30: the track has a second color (`Track::fade_color_bottom`, white by default and
    not written while white), the envelope ranges from -1 to 1 (`AutomationTarget::VideoFade` bounds), and
    `envelope::fade_mix` picks the color by the sign (positive: `fade_color`, the top one; negative: the bottom
    one) and uses the size of the value as the amount. Old projects keep their behavior: their envelopes stay at
    or above zero, so they still go to the one color they had. The video effects panel shows one swatch row per
    color and each change is one undo step (`SetFadeColor { bottom, .. }`).
  - Still open (small task): the default top and bottom colors of NEW tracks from the preferences (the Video tab
    of the reference); Neoveg new tracks start with black on top and white at the bottom. The manual does not
    give the default values. [NOT DOCUMENTED]
  - Gap (small task): the automation modes of the Fade slider (Off / Read / Touch / Latch) follow the general
    automation recording item of the roadmap, not this one.
Sources: VEGAS_Pro_18_EN.pdf p. 241 (and 230, 533 from the index); manual_vegaspro21_en.pdf pp. 1017-1018.

53. Feature Name: Video Event Edge Frames (Split-Screen Preview While Slipping and Sliding)
----------------------------------------------------------------------
Classic NLE Exact Behavior:
  (Read from VEGAS_Pro_18_EN.pdf, the paragraph on split-screen previews in the Video Preview section just before
   "Showing affected and unprocessed video", p. 431, with cross references to "Adjusting an event's length" p. 142 and "Slipping and sliding events" p. 147;
   manual_vegaspro21_en.pdf, View menu and the keyboard shortcut table.)
  - The Video Preview window "temporarily enters split-screen preview mode" while the user performs an event
    slip, an event slip-trim, an event slide, or a crossfade / transition slide. The split screen shows the
    event's first and last frame as the edit changes. [OFFICIAL]
  - View > Video Event Edge Frames turns this on or off; Ctrl+Shift+O toggles it (the shortcut table words it
    as showing "the frame under the cursor or split-screen previews" during those edits). [OFFICIAL]
  - It is a preview mode, not a drawing on the event in the timeline; the gap analysis called it an overlay
    "on the event" because the menu list was terse. [OFFICIAL]
  - The manual does not say how the two frames are laid out or whether the preview keeps playing. [NOT DOCUMENTED]
Visual/Technical Rules:
  - Two frames of the edited event side by side while the drag lasts: the first (the in point at the start of
    the event on the timeline) and the last (the frame just before the event ends). When the drag ends the
    preview returns to the normal single frame.
Implementation Guidelines for Neoveg:
  - Implemented on 2026-10-30 (see the Neoveg design below): `view.event_edge_frames` (Ctrl+Shift+O, View menu,
    preference `show_event_edge_frames`, on by default), `velocity::edge_times` for the two source times, the
    module `neoveg_ui::edge_frames` for the halves, and the frame worker's source-frame request for the pictures.
    The crossfade / transition slide has no Neoveg counterpart yet. Prerequisites that existed: slip and slide by mouse and keyboard (`edit::slip`, `edit::slide`,
    the Slip / Slide tools), the frame worker that decodes any frame of a clip on request, and a preview window.
  - Neoveg design (small task): a View toggle and the command `view.event_edge_frames` (Ctrl+Shift+O, a
    preference remembered with `#[serde(default)]`, on by default as in the reference). While a slip, slide or
    slip-trim drag is active, the preview asks the worker for the event's first and last source frames (trim_in
    and trim_in + duration at the clip's speed, honoring a velocity envelope through `velocity::source_offset`)
    and draws them left and right of the preview with the timecode of each. Two decodes per drag step: use the
    existing source-frame cache so a drag that moves a frame at a time does not decode from scratch.
  - Crossfade / transition slide has no Neoveg counterpart yet; add it with that edit.
  - Ordering: do it with the expanded edit mode item (README plan, phase 2), which also needs the two-sided
    preview; they can share the split preview widget.
Sources: VEGAS_Pro_18_EN.pdf p. 431 (see also pp. 142 and 147); manual_vegaspro21_en.pdf (View menu, shortcut table).
Research Date: 2026-10-30
